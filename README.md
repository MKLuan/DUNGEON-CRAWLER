# ⚔️ Dungeon Crawler

*Um jogo clássico de exploração de masmorras desenvolvido em linguagem C.*

## 📝 Sobre o Projeto

Este projeto foi criado como uma iniciativa pessoal para aprimorar a lógica de programação e ganhar experiência prática no desenvolvimento de código utilizando a linguagem C. 

A aventura começa em uma pacata vila, que serve como ponto de partida seguro para o jogador. O objetivo principal é desbravar os níveis cada vez mais profundos e perigosos de uma masmorra, superando desafios até o grande confronto épico contra o Boss final. Para auxiliar novos aventureiros, o sistema conta com um menu inicial interativo e um tutorial integrado explicando as mecânicas.

## 🎮 Controles

A movimentação do personagem é fluida e baseada nos comandos clássicos de teclado:

*   **W:** Mover para Cima
*   **A:** Mover para a Esquerda
*   **S:** Mover para Baixo
*   **D:** Mover para a Direita
* (entre outros comandos)
## 🛠️ Tecnologias Utilizadas
*   **Linguagem principal:** C
